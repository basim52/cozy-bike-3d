# 🚲 جولة دراجة الضاحية | Cozy Downhill Bike 3D

لعبة ثلاثية الأبعاد (3D) بطابع أنمي وأجواء استوديو جيبلي الصيفية، مصممة لتعمل بسلاسة فائقة على متصفحات الجوال والكمبيوتر مع تحكم لمس سهل ومريح.

---

## 🌟 مميزات اللعبة

- **منحدر ضاحية ساحر (Downhill Slope):** تجول بدراجتك على طريق منحدر مطل على وادٍ وجبال وأفق صيفي خلاب وغيوم ركامية ناعمة.
- **عناصر مطابقة للمشهد:** منازل بريف أمريكي/ياباني، أسوار خشبية بيضاء، صناديق بريد، وحاويات قمامة خضراء على جانب الطريق.
- **شخصية ودراجة ثلاثية الأبعاد:** دراجة حمراء مع دوران عجلات واقعي، وراكب بحقيبة ظهر صفراء وقبعة خضراء مع تحريك أرجل التبديل ديناميكياً.
- **نمط تسليم الجرائد (Paper Delivery):** ارمِ الجرائد نحو صناديق البريد لكسب النقاط والنغمات الاحتفالية.
- **نجوم ذهبية وقفز:** اجمع النجوم واقفز فوق الأرصفة والمنحدرات مع مؤثرات اهتزاز (Haptics Vibration) على الجوال.
- **أصوات واقعية وموسيقى مركبة:** رنين جرس الدراجة، صوت النسيم المتصاعد مع السرعة، وموسيقى هادئة دون الحاجة لأي ملفات صوتية خارجية (Web Audio API Synth).
- **شاشات وعدادات (HUD):** عداد سرعة رقمي (كم/ساعة)، عداد مسافة، ورادار خريطة مصغرة يوضح موقع المنازل.

---

## 🎮 التحكم

### 📱 على شاشات الجوال (Touch Controls):
- **الإبهام الأيسر (`◀` و `▶`):** توجيه وانعطاف سلس للدراجة.
- **⚡ دواسة (Pedal):** التبديل وتسريع الانحدار.
- **🛑 فرامل (Brake):** إبطاء الدراجة أو التوقف.
- **🗞️ رمي (Throw):** قذف الجريدة نحو صناديق البريد.
- **🔔 جرس (Bell):** رن جرس الدراجة.
- **🦘 قفز (Jump):** القفز بالدراجة.
- **⛶ ملء الشاشة:** إخفاء أشرطة المتصفح لتجربة لعب كاملة.

### 💻 على لوحة مفاتيح الكمبيوتر (Keyboard Controls):
- **W / السهم للأعلى:** دواسة وتسريع
- **S / السهم للأسفل:** فرامل
- **A / D أو الأسهم يمين/يسار:** توجيه الدراجة
- **مسافة (Space):** قفز
- **E أو F:** رمي الجريدة
- **B:** رن الجرس
- **C:** تبديل منظور الكاميرا (خلفية، مقربة، أول شخص)

---

## 🚀 تشغيل اللعبة محلياً

فقط افتح ملف `index.html` في أي متصفح حديث (Chrome, Edge, Safari, Firefox).
أو للعب من الجوال على نفس الشبكة:
```bash
python server.py
```
ثم افتح الرابط المعروض في المتصفح.
